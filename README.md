# قاموس لغة الإشارة التفاعلي

صفحة واحدة (index.html) تعمل مباشرة على GitHub Pages.

## طريقة النشر
1. أنشئ Repository جديد على GitHub.
2. ارفع الملفات (index.html و README.md) إلى الـ Repository.
3. من Settings ← Pages ← Source: اختر Deploy from a branch ثم main و / (root) ثم Save.
4. بعد دقيقة أو اثنتين يظهر الرابط: https://USERNAME.github.io/REPO-NAME/

ملاحظة: الصور والتعديلات تُحفظ داخل متصفح كل مستخدم فقط.
